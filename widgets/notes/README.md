# Заметки — исходники виджета

Самостоятельное приложение для Windows с локальными записями, бумажными стикерами поверх окон, рисунками и напоминаниями.

[Описание возможностей и изображения интерфейса](../../README.md) · [Установщик Windows x64](https://github.com/Keksichek/mini-player/releases/download/notes-v0.1.4/Notes-Setup.exe)

## Запуск готовой версии

Запустите `Notes-Setup.exe`, выберите папку и нажмите «Установить». Установщик создаст ярлыки на рабочем столе и в меню «Пуск». Python включён в готовую сборку.

Путь по умолчанию — `%LOCALAPPDATA%\Programs\Notes`. Папка должна быть доступна для записи, поскольку личные данные сохраняются рядом с EXE.

## Запуск из исходников

Нужны Windows x64 и Python 3.12 или новее с Tkinter. Код приложения использует стандартную библиотеку Python.

1. Скачайте ветку `feature/notes-widget` и откройте `widgets/notes/`.
2. Запустите `launch.bat` или выполните из этой папки:

```powershell
py -3 app.py
```

Для фонового запуска:

```powershell
py -3 app.py --tray
```

В готовой сборке тот же режим доступен через `Notes.exe --tray`.

## Где хранятся данные

Папка `data/` создаётся автоматически при первом запуске. Остальные файлы появляются по мере использования.

| Файл | Содержимое |
| --- | --- |
| `data/notes.json` | Блоки, текстовые записи, рисунки, напоминания и отметки выполнения |
| `data/settings.json` | Выбранная тема |
| `data/stickers.json` | Закреплённые листы и их цвета |
| `data/reminder-custom.wav` | Пользовательский звук |

При запуске исходников `data/` создаётся рядом с `app.py`, в готовой сборке — рядом с `Notes.exe`. Папка исключена из Git и не входит в установщик. Для резервного копирования закройте программу и скопируйте `data/`.

Автозапуск сохраняется в настройках текущего пользователя Windows. MP3 преобразуется в WAV средствами Windows без дополнительной установки конвертера.

## Основные модули

| Файл | Назначение |
| --- | --- |
| `app.py` | Запуск окна, размещение на экране и режим трея |
| `installer.py` | Установка в выбранную папку и создание ярлыков |
| `notes/model.py` | Модель блоков и записей, JSON-хранилище, поиск наступивших напоминаний |
| `notes/ui.py` | Главное окно, темы, редакторы и настройки |
| `notes/sticky.py` | Бумажные стикеры и синхронизация записей |
| `notes/drawing.py` | Рисование, ластик, отмена и повтор |
| `notes/date_picker.py` | Календарь и выбор времени |
| `notes/reminders.py` | Всплывающие карточки и системные уведомления |
| `notes/sound.py`, `notes/convert_audio.ps1` | Выбор сигнала и импорт MP3 |
| `notes/scrollbar.py` | Ползунок, появляющийся при наведении |
| `notes/windows.py` | Значок трея и автозапуск Windows |
| `notes/uninstall.py`, `notes/install_paths.py` | Удаление файлов виджета и созданных ярлыков |

У блока есть основная запись и дополнительные записи. У каждой записи свои текст, отметка выполнения и дата напоминания. Рисунок хранится вместе с записью. Стикер и главный список используют одно хранилище.

## Сборка EXE и установщика

В отдельном окружении Python установите PyInstaller:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pyinstaller
.\build.ps1
```

Результаты сборки:

- `dist/Notes/` — переносимая папка с `Notes.exe` и `_internal/`.
- `dist/Notes-Setup.exe` — установщик с выбором папки и созданием ярлыков.

Переносимую папку распространяйте целиком. В готовый пакет включаются иконка, стандартный сигнал и сценарий преобразования MP3. Перед публикацией убедитесь, что в пакет не попала папка `data/`.

## Работа напоминаний и удаление

Расписание проверяется каждые 15 секунд, пока приложение запущено. Выполненные записи пропускаются. Просроченное активное напоминание появляется при следующем запуске. В фоне приложение продолжает проверять расписание.

Удаление приложения требует подтверждения. Оно очищает файлы этой копии виджета, личные данные, автозапуск и ярлыки установщика. Выбранная папка установки остаётся на месте. Посторонние файлы, скачанный установщик и вручную созданные ярлыки удаляются отдельно.

## Интеграция с лаунчером

Текущий вход для запуска — `app.py` или `Notes.exe`. Режим `--tray` позволяет стартовать в фоне. Для установки через хаб используется пакет notes.zip и версия лаунчера с поддержкой EXE-виджетов.

### Работа в VibeWidgetsHub

Сборка теперь создаёт также `dist/notes.zip`: переносимую папку Notes.exe и _internal без личных данных. Этот архив передаётся сборке лаунчера параметром `-NotesPackage`. Отдельный Notes-Setup.exe остаётся для самостоятельной установки.

В режиме хаба приложение поддерживает `--launcher-root`, `--data-dir`, `--show-existing` и общие именованные события `.Ready`, `.Show`, `.Stop`. Папка данных строго привязана к `<хаб>/Data/notes`; установленный EXE распознаёт этот режим и при прямом запуске. Разные установки хаба имеют независимые экземпляры. Самостоятельная версия продолжает использовать data рядом с EXE.

Удалять управляемую копию и настраивать её автозапуск следует через хаб. Удаление виджета через хаб сохраняет Data/notes. Старые самостоятельные записи автоматически не переносятся: закройте обе версии и при необходимости скопируйте содержимое старой папки data в Data/notes, предварительно сохранив резервную копию.

Проверка протокола: `python -m unittest test_launcher -v`.
