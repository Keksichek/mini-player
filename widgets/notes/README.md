# Заметки

Локальный список дел в виде отрывного бумажного листа. Приложение написано на Python и Tkinter, не требует установки сторонних библиотек. Заметки хранятся в `data/notes.json`. Выбранная тема сохраняется в `data/settings.json`.

## Запуск

1. Скопируйте папку `widgets/notes` или распакуйте её в доступное для записи место.
2. Установите Python 3.12 или новее для Windows с Tkinter. В установщике можно включить Add Python to PATH.
3. Запустите `launch.bat` или выполните `py -3 app.py` из папки виджета.

При первом запуске виджет создаст пустой файл `data/notes.json`. Файлы настроек, закреплённых стикеров и выбранного звука создаются по мере использования. Папка `data/` хранится на компьютере пользователя и исключена из Git. При обновлении версии сохраните её.

Для запуска из будущего лаунчера используется `app.py`. Ключ `--tray` запускает виджет в фоне. В режиме автозапуска приложение запускается при входе в Windows.

## Возможности

- Добавление, редактирование, выполнение и удаление задач.
- Дата и время напоминания на каждую задачу.
- Уведомление Windows с заголовком и текстом задачи, звуковой сигнал.
- Сохранение после каждого изменения; кириллица в UTF-8.
- Фильтры для всех, активных и выполненных задач. Кнопка в правом верхнем углу переключает светлую и тёмную темы.

## Архитектура

- `app.py` — запуск и сборка окна.
- `notes/model.py` — модель и JSON-хранилище.
- `notes/reminders.py` — проверка расписания и уведомления.
- `notes/ui.py` — бумажный интерфейс и диалоги.

Приложение рассчитано на Windows. Уведомления Windows показываются через PowerShell Toast API. Если политика уведомлений Windows их отключает, звуковой сигнал всё равно сработает, пока приложение запущено.


## Стикеры

Нажмите «Закрепить» рядом с делом. Бумажный стикер появится поверх обычных окон. Перетаскивайте его за цветную полоску и меняйте размер за нижний правый угол. Кнопка «Цвет» перебирает пять оттенков и сохраняет выбор. Крестик убирает стикер с экрана. Само дело остаётся в списке.

Главное окно можно свернуть. При выходе из приложения стикеры закрываются, а при следующем запуске закреплённые дела снова появляются на экране.


- Нажмите «＋», чтобы добавить текст, напоминание или рисунок на этот лист. У каждой записи своя отметка выполнения. Выполненные напоминания пропускаются.
- В редакторе рисунка доступны цветные чернила, ластик, отмена и повтор. Наведите указатель на значок рисунка для просмотра или нажмите на него, чтобы открыть редактор.
- Если записи не помещаются, прокручивайте лист колёсиком. Узкий ползунок виден при наведении на стикер.

## Блоки

Записи, добавленные через «＋» на стикере, сразу появляются внутри его блока в главном окне. Отметки выполнения синхронизируются в обе стороны. Чтобы назвать блок, откройте «Править» и заполните поле «Название блока». Оно также появится на стикере.

Узкий ползунок в главном окне появляется при наведении на список, если все записи не помещаются. Список также можно прокручивать колёсиком.

## Удаление и редактирование

- «Выбрать для удаления» открывает список блоков и напоминаний. Щёлкните по нужным строкам и подтвердите действие. Удаление блока удаляет все его записи. Удаление напоминания снимает дату и время, сохраняя запись.
- «Удалить все уведомления» снимает все напоминания после подтверждения. Блоки, тексты и рисунки сохраняются.
- В окне «Править» выберите нужную запись из списка. Можно изменить несколько записей по очереди и сохранить все правки одной кнопкой.

## Звук и цвет напоминаний

Всплывающая карточка берёт цвет стикера, даже если он откреплён. Для листа, который ещё не закрепляли, используется жёлтый цвет.

Нажмите «Звук» в шапке окна. Здесь можно прослушать текущий сигнал, выбрать свой WAV PCM или MP3 длительностью до 30 секунд или вернуть стандартный сигнал. MP3 автоматически преобразуется в WAV средствами Windows. Подсказка об этом открывается при наведении на «!» рядом с кнопкой выбора. Сигнал сохраняется как WAV в папке приложения. Системное уведомление Windows отправляется без собственного звука, чтобы сигнал не дублировался.



## Календарь, сохранение и автозапуск

- Кнопка «Календарь» рядом с датой открывает выбор дня, часов и минут. Для напоминаний со стикера доступен тот же календарь.
- Даты, время, отметки выполнения и выбранный звук хранятся локально и переживают закрытие приложения и выключение компьютера. Если срок прошёл, пока приложение было закрыто, активное напоминание появится при следующем запуске.
- В меню «Автозапуск» можно отключить старт при входе в Windows, открыть главное окно или запустить приложение в фоне. В фоновом режиме окно и стикеры скрыты. Щелчок по значку возле часов открывает заметки. Windows может показывать значок в области скрытых значков. Правый щелчок позволяет выйти.
